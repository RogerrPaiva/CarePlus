# CarePlus

Aplicação web de saúde com gamificação.

Stack:
- React
- Python
- JSON

# Objetivos
CarePlus é um aplicativo de saúde que utiliza gamificação para incentivar hábitos saudáveis. Os usuários realizam missões diárias, como caminhar ou cumprir metas de atividade física, mantendo um streak (sequência de dias consecutivos), semelhante ao sistema usado no Duolingo. Ao completar essas missões, o usuário ganha moedas virtuais como recompensa.

Essas moedas podem ser usadas dentro de um mini-jogo integrado ao aplicativo, onde o usuário possui um “mundinho” personalizável, inspirado em jogos como Pou. Nesse espaço, será possível customizar o ambiente, desbloquear itens e evoluir o mundo virtual, transformando o cuidado com a saúde em uma experiência divertida.

Além disso, o projeto inclui uma pulseira inteligente integrada ao aplicativo, responsável por registrar dados como quantidade de passos e atividade física, que influenciam diretamente nas missões e recompensas do sistema.

Para usuários que não desejam utilizar a parte de jogo, o aplicativo também permitirá trocar as moedas acumuladas por recompensas reais em uma loja mensal, como garrafas, bolsas ou até descontos no plano de saúde, garantindo que todos possam se beneficiar do sistema de recompensas enquanto mantêm hábitos saudáveis.
